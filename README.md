## 一、建立遊戲與匯入素材
  我先在Unity 建立 2D 遊戲專案，將人物圖片與背景素材匯入 Assets 資料夾，再將人物放入
  場景中。透過 C# 腳本控制人物，將腳本掛載到人物物件上，讓程式可以控制人物的動作。
## 二、調整畫面與遊戲設定
  新增完角色背景後，調整了物件的顯示順序，透過 Sorting Layer 和 Order in Layer
  控制背景、人物與其他物件的前後關係。
## 三、製作人物移動功能
  先設定人物的起點與終點，並利用 Vector2 和方向陣列儲存移動方向，再透過鍵盤控制人物
  移動。
  - 按左右的方向鍵，人物可以左右移動。
  - 設定移動的速度，讓人物可以平順移動。
  - 利用起點與終點的座標，判斷人物有沒有抵達終點，抵達後就回到起點。
  也設定了人物的起始座標和終點座標，固定人物的開始和結束位置。
## 四、增加跳躍與蹲下功能
  替人物新增 Rigidbody2D，利用重力製作跳躍功能。
  - 按下上方向鍵，人物可以跳躍。
  - 按住下方向鍵，人物會縮小高度，呈現蹲下的效果。
  - 調整人物的移動邏輯，讓跳躍時仍然可以同時左右移動。
  也設定人物移動方向與圖片翻轉的效果，讓人物往左移動時會面向左邊，往右移動時則恢復
  正常方向。
## 五、設定遊戲邊界與碰撞效果
  使用 Mathf.Clamp() 固定人物的 X、Y 座標，讓人物不會移動到場景範圍外。
  在場景中加入地面和障礙物，新增 Collider2D 偵測碰撞，人物碰到障礙物就回到起點。
  為了讓程式辨識不同障礙物，觸發不同音效，在障礙物設定 Obstacle Tag，並透過
  OnCollisionEnter2D() 判斷有沒有發生碰撞。
因為人物碰撞後會翻覆，調整了 Rigidbody2D 的 Constraints，讓人物不會旋轉。
## 六、加入音效功能
  加入各種音效，使遊玩碰到不一樣的狀況時有不一樣的聲音效果。
  * 移動音效： 人物左右移動時持續播放，停止時暫停播放。
  * 障礙物音效： 人物碰到障礙物時播放一次。
  * 終點音效： 人物抵達終點時播放一次。
把音效檔匯入 Assets 資料夾，透過 AudioSource 和 AudioClip 設定音效，用程式控制
音效播放。
